## По пунктам Роберта

1. **Синие линии не видел** — см. выше: они были в потерянной части.
2. **Знаки ‖ видел** — теперь причина берётся из журнала (D‑55); добавлено
   «Продолжение после остановки» вместо ошибочной «Паузы» на последнем разрыве.
3. **Архив → активная прогулка → «просмотр»** — баг `selectExpedition`
   (D‑56). Активная экспедиция теперь открывается в режиме записи, путь читается
   из базы, пустой state в базу не пишется.
4. **После перезапуска продолжилась сама** — да, `endTime` был `null`,
   `loadData` автоматически включил запись; `expedition-resume` в журнале нет.
5. **Превью находок не появлялись** — эффект маркеров запускался до монтирования
   карты. Маркеры переехали в `FindingsLayer` внутри `MapContainer` (D‑57).
6. **Чёрные поля в кружках** — Leaflet принудительно ставит маркерным `img`
   `width: auto`, портретное фото не заполняло круг. CSS усилен (D‑57).
7. **«Чизкейк» дважды** — в данных оказались **две цели** (#24 и #25): новая цель
   не снимала флаг с прежней. Теперь снимает, маркеры дедуплицируются по id (D‑57).
