# 🗺️ Дневник Исследователя (Researcher's Diary)

## 🎯 Концепция и Цели

Приватное PWA для записи маршрутов и сбора «находок» (фото + заметки). Данные хранятся строго локально в браузере (IndexedDB). Пользователь ставит цель перед прогулкой, фиксирует находки в процессе и возвращается к ним в архиве.

### Первичное ТЗ (Core Vision):

1. **Карта**: Визуализация перемещений и отметок.
2. **Целеполагание**: Перед прогулкой создается карточка маршрута с конкретной целью (например, «найти белый цикорий»).
3. **Процесс сбора**: Во время прогулки пользователь фиксирует объекты (фото + краткое описание). Каждая находка привязывается к координатам и времени.
4. **Итог**: После прогулки формируется summary (отчет), где видно весь путь, все находки и время их обнаружения.
5. **Архив**: Возможность возвращаться к прошлым маршрутам и изучать историю своих открытий.

## 🛠 Технический стек

- **Frontend**: React, Vite
- **Карты**: Leaflet.js, react-leaflet
- **База данных**: Dexie.js (обертка над IndexedDB)
- **Стили**: CSS (App.css)

### 💾 Структура БД (Dexie)

- `expeditions`:
  - `id` (primary key)
  - `startTime` (Date)
  - `endTime` (Date, optional)
  - `title` (string)
  - `goal` (string)
  - `path` (Array of `[lat, lng]`)
- `findings`:
  - `id` (primary key)
  - `expeditionId` (index)
  - `position` (`[lat, lng]`)
  - `timeStamp` (Date)
  - `note` (string)
  - `image` (Base64 string)
  - `isGoal` (boolean)

## 🏗 Текущая Архитектура (v0.3)

- `App.jsx`: Главный контроллер. Управляет стейтами `view`, `isWalking`, `currentExpeditionId` и импортом/экспортом данных.
- `Archive.jsx`: Список экспедиций с превью-фото и кнопками управления данными (бэкап).
- `MapView.jsx`: Карта с трекингом, Polyline и кастомными фото-маркерами.
- `SummaryView.jsx`: Итоговый отчет с расчетом времени, дистанции и средней скорости.
- `utils.js`: Математические утилиты (Формула Гаверсинусов для расчета расстояний).
- `FindingsLog.jsx`, `FindingModal.jsx`, `StartExpeditionModal.jsx`: Вспомогательные интерфейсы.

## 🛠 Правила разработки и именования

- **Читаемость кода**: Приотет понятности над краткостью.
- **Запрет сокращений**: Не использовать сокращенные имена переменных (например, `f` -> `finding`, `exp` -> `expedition`).
- **Постепенный рефакторинг**: Перенос inline-стилей в CSS-классы по мере работы с файлами.
